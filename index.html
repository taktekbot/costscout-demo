limit-far-above-request (1)

Fix: Lower the limit or raise the request; large gaps make node packing unpredictable

  • shop/web/web: Memory limit is 8.0x the request

many-replicas (1)

Fix: Check whether an autoscaler (HPA) should own the replica count, or whether fewer replicas suffice

  • shop/Deployment/api: 5 replicas

missing-memory-limit (2)

Fix: Set a memory limit so one container can't starve its node

  • monitoring/node-exporter/exporter: No memory limit
  • shop/api/api: No memory limit

missing-requests (1)

Fix: Set requests from observed usage so the scheduler and the cost allocation can see this workload

  • monitoring/node-exporter/exporter: CPU or memory request not set

unpinned-image (2)

Fix: Pin a version tag or digest so rollouts are reproducible

  • monitoring/node-exporter/exporter: Image is untagged or uses :latest (prom/node-exporter)
  • shop/api/api: Image is untagged or uses :latest (acme/api:latest)
